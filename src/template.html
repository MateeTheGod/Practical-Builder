How it works. FINAL = base + height effect + wingspan-over-height effect + weight effect + body type + anomaly, rounded once and capped at 99. Badge names and thresholds come from a community badge sheet and have not been verified in the current game. Tiers 1–5 are its five rows in order. Where a rule says "/" or "or", any one option counts.
